# Agent Instructions

`AGENTS.md` is the high-signal root constitution. This folder contains the
detailed policies referenced by it.

| File | Purpose |
|---|---|
| `WORKFLOW.md` | Expanded task lifecycle and planning |
| `TOOL-ROUTING.md` | Matt Pocock, Graphify, Serena, Impeccable, Context Mode |
| `CONTEXT-MODE.md` | Context-efficient exploration and processing |
| `ANTI-SLOP.md` | Scope, complexity, and quality controls |
| `VERIFICATION.md` | Testing and conditional browser/UI verification |
| `SECURITY.md` | Security and data-integrity rules |
| `DEFINITION-OF-DONE.md` | Final completion checklist |

Do not blindly read every file for every task. Read the policy relevant to the
current task.

Keep project-specific truth in the project's own `docs/` (PRD, architecture,
IA, design, ADRs, decisions, etc.). This folder defines how the agent works;
project docs define what the project is and should do.
